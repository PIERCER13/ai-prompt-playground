# Piercer AI Prompt Playground (BYOK)

Teste prompts lado a lado (OpenAI, Gemini, Groq, Ollama local) com tempo de resposta e custo por tokens

## Funcionalidades

- **Seções principais**: Modelo A, Modelo B
- **Ações disponíveis**: Executar A/B
- **Persistência automática**: salva alterações automaticamente no navegador (`localStorage`).
- **Multilíngue**: suporte integrado com botão de troca de idioma (`PT / EN / ES`).

## Como Executar

1. Execute `start.bat` para iniciar o servidor local na porta `8144`, ou abra `index.html` diretamente no navegador.
2. Acesse `http://localhost:8144`.
