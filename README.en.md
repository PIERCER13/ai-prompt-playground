# Piercer AI Prompt Playground (BYOK)

Teste prompts side by side (OpenAI, Gemini, Groq, Ollama local) with tempo of resposta and cost per tokens

## Features

- **Main Sections**: Modelo A, Modelo B
- **Available Actions**: Executar A/B
- **Auto-Save**: automatically persists changes in the browser (`localStorage`).
- **Multi-Language**: built-in language switcher (`PT / EN / ES`).

## How to Run

1. Run `start.bat` to start the local server on port `8144`, or open `index.html` directly in your browser.
2. Open `http://localhost:8144`.
